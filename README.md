# Assignment 01 - Getting Started with GitHub

## Program Description
This C++ program calculates the sum of the first 50 natural numbers using two different approaches:
1. An iterative `for` loop function (`calculateSumLoop`).
2. A mathematical verification formula function (`calculateSumFormula`) using `n(n+1)/2`.

Both methods calculate and verify the total sum of numbers from 1 to 50.

## Output / Sample Run
Sum of first 50 natural numbers (loop): 1275
Sum using formula n(n+1)/2: 1275
